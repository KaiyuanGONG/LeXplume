# Support

For help with LeXplume, email [support@lexplume.com](mailto:support@lexplume.com). Initial support is available in Chinese and English, with a target first response within three working days. This target is not a guaranteed service level.

Please include:

- the app version and whether you are using Web, installed PWA or an official Android build;
- browser/Android version and device type;
- the action you were attempting;
- the exact error text and the time it occurred; and
- redacted steps that reproduce the problem.

Never send a password, API key, access token, private legal information, reviewer access details, or an unredacted JSON backup. Screenshots should be checked for account identity and private learning material first.
