# LeXplume

**把真实阅读中遇见的词，变成真正能回忆起来的词汇。**

[English](README.md) · [Français](README.fr.md)

![LeXplume — 在语境中理解，在恰当时机复习](assets/github-hero-1600x600.png)

[官网](https://lexplume.com) · [产品逻辑](PRODUCT.md) · [支持邮箱](mailto:support@lexplume.com) · [隐私政策](https://lexplume.com/privacy)

LeXplume 是一款面向独立成年人的中文优先英语/法语词汇应用。它把真实材料里的词、原句语境、简明解释和 FSRS 复习连成一条专注的学习流程，同时避免让云端账号或 AI 订阅成为学习的前提。

## 为什么做 LeXplume

- **通用词表与你当下的阅读无关。** LeXplume 从你主动选择的材料开始。
- **脱离语境的查询很快会被忘记。** 每个词都可以保留让它产生意义的原句。
- **手工制卡会打断阅读。** 拾词、理解和复习在同一条流程里完成。
- **完全依赖云端会削弱控制感。** 核心词库与复习记录本地优先、可离线使用，并支持 JSON 备份。

## 学习闭环

**遇见 → 拾取 → 理解 → 复习 → 留存与运用**

1. 在真实阅读中遇见有价值的英语或法语词。
2. 拾取词或短语，同时保存原句。
3. 用词典语境和可选 AI 辅助理解。
4. 在 FSRS 判断记忆需要加固时复习。
5. 通过回忆、拼写、听写和填句留存并运用。

## 核心能力

- 从文本或图片文字中拾取词汇并保留句子语境。
- 本地优先的词库，以及 JSON 导出与恢复。
- 闪卡、拼写、听写和填句形式的 FSRS 复习。
- 默认学习英语，也可独立开启法语。
- 界面语言、释义语言和所学词语言互相独立。
- 可选浏览器直连 AI，自备密钥仅保存在本机；符合资格的邀请账号可使用有上限的托管服务。
- 可选账号同步只是云端镜像，不替代本地运行时数据。

## 设计出发点

LeXplume 采用安静的 **Paper** 视觉语言：温暖的中性色、编辑感字体、克制的信息层级和充足留白，让注意力停留在词与原句。**Semantic Fold** 标志由“一个连续主体＋一个负空间焦点”构成，表达语言被拾取、理解和留存；它在纯单色和小尺寸下仍然成立。

完整说明见 [产品与设计逻辑](PRODUCT.md)。

## 当前状态

LeXplume 1.0 正在准备免费的邀请制 Beta，仅面向 18 岁及以上独立成人。现在没有公开注册、付费服务或公开 Google Play 版本，也不把中国大陆作为主动推广市场。

[lexplume.com](https://lexplume.com) 的 Web/PWA 是规范产品入口。Android Trusted Web Activity 仍在发布前测试。

## 本地优先与隐私

运行中的词库和复习状态默认保存在当前浏览器。可选账号同步只是云端镜像。浏览器直连 AI 的密钥留在设备上，不进入 JSON 备份或同步。启用可选 AI 前，请阅读最新[隐私政策](https://lexplume.com/privacy)。
