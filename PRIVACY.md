# Privacy

The canonical LeXplume privacy policy is published at [https://lexplume.com/privacy](https://lexplume.com/privacy). The live policy controls if this summary differs from it.

## Plain-language summary

- Vocabulary, review history, notes and settings are stored locally in browser storage by default.
- JSON backup is initiated by the user. Browser-direct AI keys are excluded from backup and optional sync.
- An eligible signed-in user may enable an optional cloud mirror for supported records.
- AI features send the minimum content needed for the requested explanation, chat, enrichment or image-text operation to the selected provider. Provider terms also apply.
- Operational security controls may process account, request-count and limited network/device signals.
- LeXplume does not include advertising or payment processing in the invite-only Beta.

Use [https://lexplume.com/delete-account](https://lexplume.com/delete-account) for the current account-deletion instructions. Deleting a cloud account and clearing local browser data are separate choices, because LeXplume is local-first.

Questions can be sent to [support@lexplume.com](mailto:support@lexplume.com). Do not send passwords, API keys or an exported vocabulary file by email.
