# Contributing product feedback

This repository accepts product feedback and corrections to its public information. The LeXplume application source remains private and is not part of this repository, so application-code pull requests cannot be reviewed here.

Before opening an issue:

1. Check [FAQ.md](FAQ.md) and [SUPPORT.md](SUPPORT.md).
2. Remove account identifiers, private learning material, credentials, API keys and exported data.
3. Describe one problem or request per issue, with the affected version and platform.
4. Keep examples minimal and safe to publish.

Documentation corrections may be proposed through a focused pull request. By submitting text, you confirm that you have the right to provide it and allow the repository owner to use and edit it in LeXplume product information.

Security or privacy vulnerabilities must follow [SECURITY.md](SECURITY.md); do not disclose them in an issue or pull request.

Participation must remain respectful and relevant. Spam, harassment, child-directed access requests, attempts to trade invitations, and requests for credentials will be closed.
