# Public repository assets

- `logo.svg` is the approved current-colour Semantic Fold master for documentation use.
- `logo-512.png` is the approved Paper-ink app icon export.
- `github-hero-1600x600.png` is the selected repository hero generated from the same mark.
- `screenshot-capture.jpeg`, `screenshot-review.jpeg` and `screenshot-local-first.jpeg` are earlier unedited 1,080 × 1,920 captures from the real local PWA using fictitious data.
- `readme/zh/` (Chinese interface) and `readme/en/` (English interface) hold the README images. Each folder has the same five files, 1,760 px wide:
  - `hero-light.webp` and `hero-dark.webp`: the Capture page on a computer and a review card on a phone, in the light and dark themes.
  - `steps.webp`: the Capture, Understand and Review screens side by side.
  - `domain.webp`: the domain explanation of `alignment` for bioinformatics and for machine learning.
  - `grow.webp`: recommendations from your library, the English library and the French library.

The README images are compositions of real LeXplume 1.0.0 interface captures, made from the same scripted capture set as the product site. They use fictitious demo data and contain no real account data, email address, API key or provider secret.
